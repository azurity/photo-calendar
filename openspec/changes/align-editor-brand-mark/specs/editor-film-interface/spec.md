# Spec Delta

## ADDED Requirements

### Requirement: 品牌标志一致性

编辑器应用壳左上角的品牌标记 SHALL 复用展示端的同一图形：18×18、非对称圆角、2px 描边、径向高光与 -12° 倾斜。标记 SHALL 使用编辑器暗房主题的强调色 token 着色，保持 `aria-hidden`，且不得遮挡或挤压品牌文字与导航。

#### Scenario: 与展示端同一图形

- **WHEN** 用户打开编辑器并查看左上角品牌标记
- **THEN** 标记的图形、18×18 尺寸、非对称圆角与 -12° 倾斜与展示端一致，不再使用胶片条图形

#### Scenario: 深色侧栏中的可辨识度

- **WHEN** 品牌标记出现在暗房侧栏的深色背景上
- **THEN** 描边与径向高光使用编辑器强调色 token，标记清晰可辨，且不依赖展示端的砖红色值

#### Scenario: 装饰不改变布局

- **WHEN** 品牌标记与「照片日历 / 编辑器」文字、导航同时出现
- **THEN** 标记仍是 `aria-hidden` 的纯展示元素，不拦截指针、不遮挡文字，品牌文字与导航仍完整可读

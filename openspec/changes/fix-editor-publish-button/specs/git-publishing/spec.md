# Spec Delta

## ADDED Requirements

### Requirement: 发布入口

编辑器 SHALL 在侧栏提供常驻的发布卡片，已配置站点仓库时显示发布状态与「发布」按钮，未配置时显示「去设置」入口。点击「发布」SHALL 触发一次 Git 发布；发布进行中入口 MUST 禁用并显示进行中状态，且不得启动第二次发布。

#### Scenario: 已配置仓库时显示发布入口

- **WHEN** 用户打开已配置站点仓库的编辑器
- **THEN** 侧栏显示发布卡片、当前发布状态与「发布」按钮，点击按钮触发一次发布

#### Scenario: 未配置仓库时引导设置

- **WHEN** 用户打开尚未配置站点仓库的编辑器
- **THEN** 侧栏发布卡片显示「尚未配置站点仓库」和「去设置」，点击「去设置」进入设置视图，不触发发布

#### Scenario: 发布进行中的入口状态

- **WHEN** 一次发布尚未结束
- **THEN** 发布入口显示进行中状态并被禁用，再次点击不会启动第二次发布

#### Scenario: 跨视图保持可用

- **WHEN** 用户在全部照片、添加照片、详情与设置之间切换
- **THEN** 侧栏发布卡片保持可见，已配置仓库时仍可直接发起发布
